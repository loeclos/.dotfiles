.dotfiles — NixOS configuration
===============================

A versatile, extensible NixOS configuration (flake + home-manager) intended as a reusable starting point for multiple machines. It provides system-level NixOS modules, user/home-manager modules, fonts and assets, and per-host overlays so the same repository can manage desktop and laptop installations.

This repository is a Nix flake that contains:
- a flake-based NixOS configuration and home-manager setups,
- assets and derivations used by those configurations (fonts, shaders, wallpapers),
- per-host configuration under hosts/, and
- reusable modules under modules/ for both NixOS and home-manager.

The flake builds and composes machine configurations; home-manager modules expose per-user configuration. The repository keeps a small number of derivations (e.g., packaging a font) and local assets required by the configuration.

Repository structure
--------------------
README.md ← this file flake.nix ← Nix flake entry (root flake) flake.lock ← flake.lock generated by nix flake update derivations/ ← small custom derivations (font packaging, etc.) assets/ ← fonts, wallpapers, and other static assets hosts/ ← per-host customizations and overlays (desktop, laptop) modules/ ← reusable NixOS and home-manager modules result ← symlink to the last build result (nix build result) users/ ← per-user / home-manager entries (e.g. users/loeclos)

Code

How it fits together
- flake.nix exposes system and home-manager outputs and references modules under modules/.
- modules/nixos contains system-level modules (packages, fonts) used by system outputs.
- modules/home contains home-manager modules and package lists included by user profiles.
- hosts/ contains host-specific overlays or small host-level packages that get composed into the relevant flake outputs.
- assets/ and derivations/ provide inputs (fonts, shader files, packaging) used by modules.

Files and contents
------------------

Top-level files
```
- README.md
  - This file: title, overview, structure, file descriptions, docs link, and license.
- flake.nix
  - Flake entry. Declares inputs, outputs for systems and home-manager profiles, and composes module sets. This is the flake root referenced by `nix build` and `nixos-rebuild build` flows.
- flake.lock
  - Lock file for flake inputs. Keeps pinned versions for reproducible builds.
- result
  - Symlink produced by Nix builds. On this repository the symlink points at the last built store path (example target: /nix/store/...-nixos-minimal-*.iso). It is a build artifact, not hand-edited content.

Directories and notable files (each entry describes the directory contents and their purpose)

- derivations/
  - satoshi-font.nix
    - Nix expression that builds/packaged the Satoshi font used by the configuration. This is the derivation used to produce a font package included in fonts lists.

- assets/
  - fonts/
    - satoshi.zip
      - Packaged Satoshi font archive (source distribution stored here).
    - satoshi/
      - (directory) likely contains unpacked Satoshi font files and auxiliary packaging files for use by derivations.
    - satoshi_true/
      - (directory) alternate layout or TrueType/OTF font files extracted for packaging or local use.
  - ghostty/
    - shaders/
      - GLSL shader source files used by the ghostty terminal/visual components (cursor trails, effects, and other shader code used by the runtime).
    - (other ghostty assets)
      - Auxiliary files (README, small scripts, or packaging hints) for integrating ghostty into the home configuration.
  - wallpaper/
    - Wallpaper image files referenced by desktop/home modules.

- hosts/
  - desktop/
    - Host-specific overlay and configuration for the desktop machine. Contains host-level NixOS config fragments, hardware overrides, and any local system services or options that differ from the generic configuration.
  - laptop/
    - Host-specific overlay and configuration for the laptop machine. Contains laptop-specific services, power management tweaks, and hardware overrides.

- modules/
  - home/
    - ghosttty.nix
      - Home-manager module configuring ghostty (user-facing terminal UI/visuals).
    - hermes-agent.nix
      - Home configuration for the Hermes agent module (user-level agent/service configuration).
    - hyperland.nix
      - Home-manager bits and keybindings for Hyperland (Wayland compositor) integration.
    - hyperrapper.nix
      - Wrappers or helper settings for Hyperland-related apps and keybindings.
    - packages.nix
      - A list of home-level packages and package sets used by the home-manager modules.
    - (other home/* .nix files)
      - Additional home-manager modules used to compose the user's environment. These collect keybindings, application settings, and per-user services.
  - nixos/
    - fonts.nix
      - System-level font package lists and font enabling used by NixOS modules.
    - packages.nix
      - System package lists used by NixOS module expressions.
    - (other nixos/* .nix files)
      - System modules and helpers consumed by flake outputs and by host overlays.

- users/
  - loeclos/
    - Per-user entries (home-manager profile definitions, user-specific configuration that ties the modules into a concrete user/profile).
```

Notes and conventions
- The repository is organized so that modules/ provides reusable building blocks and hosts/ overlays supply machine-specific differences.
- assets/ contains the static resources (fonts, wallpapers, shaders) referenced by derivations/ and modules/.
- derivations/ contains custom packaging expressions used to produce artifacts referenced by the flake.
- The flake root (flake.nix) composes the outputs and is the primary entry point for building and deploying the configuration.
